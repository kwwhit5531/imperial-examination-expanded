# READING THIS FILE
# Lines beginning with # are explanations; the game ignores them.
# Each iee_examination.NUMBER block describes one encounter. Its title, story,
# and button labels live in localization/english/iee_examination_l_english.yml.
# A trigger is a checklist: all listed requirements must pass unless OR says
# that any one is enough. NOT reverses a check. A scope names whose information
# we are reading: root is the recipient, scope:activity is their examination.
# immediate runs when the panel opens; option runs when its button is chosen.
# Positive stress makes the character more stressed; negative stress relieves it.
# Prestige is reputation and piety is religious standing; neither is exam score.
# Character animations illustrate the scene; they do not add gameplay effects.
# The original three encounters use Learning contests. The twelve additions
# have fixed outcomes: their narrative choices do not secretly roll a skill check.
# Trait-based stress adjustments are added to any ordinary stress change.
# Three choices are defined per addition, but a paid choice is hidden when
# the character cannot afford it. AI weights describe computer choices only.


namespace = iee_examination
